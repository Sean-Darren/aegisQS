# Five-minute connected demo

Run `npm ci`, set `NEXT_PUBLIC_API_MOCKING=enabled` in `.env.local`, and run `npm run dev`. Use `/en/projects/P-001/overview` on the printed port. Leave the tab open: a full reload restores the finished snapshot. Use the Senior QS preview role. Files are under `public/mock-files/`.

**Reset demo data** restores the exact finished fixtures, clears queries/uploads and cancels scheduled jobs. **Start demo story** restores a pre-story position (A-201 B current, BOQ v1, no VE-007 or procurement advice) for the following script. Both actions are development-only, mock-only, and hidden from viewers. They are not production deletion controls.

This matches `tests/e2e/demo.spec.ts`. Rehearse reliability with `npm run test:e2e -- tests/e2e/demo.spec.ts --repeat-each=3`. The test uses UI actions throughout, including the visible Start demo story action, and checks browser errors.

The finished default snapshot intentionally already contains Rev C, VE-007 and BOQ v2. Uploading identical files there creates a conflict. Start the story before rehearsing; do not resolve away duplicate warnings during the scripted run. Arbitrary drawings cannot be detected by the mock; use the supplied revisions. The Administration route is an informational empty state, not a user-management implementation.
